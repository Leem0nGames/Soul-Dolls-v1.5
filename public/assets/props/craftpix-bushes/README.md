# CraftPix top-down bushes

Forty transparent PNG props from the CraftPix free top-down bushes pack. The
collection includes simple and flowering bushes, ferns, cacti, seasonal bushes,
and damaged trees.

Use these as decorative map billboards. To load one in the current overworld,
add a `DecorationKind` and a matching `PROP_DEFS` entry in
`src/game/graphics/OverworldTiles.ts` and `src/game/graphics/OverworldProps.ts`.
Choose a footprint that matches the sprite's occupied ground area; props other
than the existing trees are currently non-blocking.
